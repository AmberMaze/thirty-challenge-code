# Thirty Challenge

Realtime, club-themed football quiz built with React + Vite + Tailwind and Supabase for realtime game sync.

Documentation has been consolidated under the `docs/` folder. Start with `docs/Guide.md` for a quick map.

## Contributing

- Install: `pnpm install`
- Dev (frontend): `pnpm run dev`
- Dev (with Netlify functions): `pnpm run dev:netlify`
